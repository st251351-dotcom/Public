今の目標は勉強を主にやって学力を伸ばすことと、部活ともうまく両立したいと思っています

一方で短所は計画を立てたりするが、行動に移すまでが遅かったり、マイペースであることや優柔不断だったりすることです。やらなきゃいけないことに対して行動が追いついてないと今後大学受験やいろんな場面で困るので少ない量を少しずつ積み重ねるという力をつけたいです
